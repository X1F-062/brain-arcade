# Beyin Arcade

## Çalıştırma
1. Node.js kur (nodejs.org, v16+).
2. Klasörde `npm start` yaz (Windows'ta `baslat.bat`'a çift tıklayabilirsin).
3. Tarayıcıda http://localhost:3000 aç. Port doluysa sunucu bir sonrakini dener, adresi terminalde yazar.

Node yoksa: `python -m http.server 8000` de çalışır (ilerleme yalnızca tarayıcıda saklanır).

## Notlar
- İlerleme hem tarayıcıda hem `data/progress.json` dosyasında tutulur. Port değişse bile kaybolmaz.
- Yapı: `index.html`, `css/style.css`, `js/app.js`, `server.js`.
